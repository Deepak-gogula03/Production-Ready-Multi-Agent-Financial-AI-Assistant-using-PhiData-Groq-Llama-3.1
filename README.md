Most AI-powered applications rely on a **single Large Language Model (LLM)** to handle every aspect of a user request, including reasoning, information retrieval, web search, and domain-specific analysis. This project adopts a **Multi-Agent AI architecture**, where multiple specialized AI agents collaborate to solve a problem more effectively. # 🤖 What is Agentic AI?

Agentic AI is an advanced approach to Artificial Intelligence in which autonomous AI agents can reason, make decisions, use external tools, and collaborate with other agents to accomplish complex tasks.

Unlike traditional AI applications that simply generate responses from a prompt, Agentic AI systems actively determine how a task should be solved by selecting appropriate tools, gathering relevant information, and coordinating specialized agents when necessary.

In this project, Agentic AI is implemented through the **PhiData Multi-Agent Framework**, where different agents work together to answer financial queries.

The system includes:

- 📈 Finance Agent
- 🌐 Web Search Agent

Each agent is equipped with dedicated tools and focuses on its own area of expertise before contributing to the final response.

This collaborative approach enables the application to generate more comprehensive and trustworthy financial insights compared to a traditional single-agent system.

### 🌟 Characteristics of Agentic AI

- Autonomous Decision Making
- Tool-Augmented Intelligence
- Multi-Agent Collaboration
- Intelligent Task Delegation

# 🔄 End-to-End Workflow

The following workflow illustrates how the system processes a financial query from start to finish.

### Step 1 — User Query

The user submits a financial question.

Example:

> Summarize analyst recommendations and share the latest news for NVIDIA.

---

### Step 2 — Query Interpretation

The Team Agent analyzes the request and identifies the required tasks.

It determines that:

- Financial data is required.
- Recent news is required.

---

### Step 3 — Task Delegation

The Team Agent delegates the work:

Finance-related tasks →

📈 Finance Agent

News-related tasks →

🌐 Web Search Agent

---

### Step 4 — Tool Execution

Each agent independently interacts with its assigned external tool.

Finance Agent →

Yahoo Finance

Web Search Agent →

DuckDuckGo Search

Both agents perform their tasks simultaneously.

---

### Step 5 — Information Retrieval

Each agent returns structured information.

Finance Agent returns:

- Stock Information
- Analyst Ratings
- Company Metrics

Web Search Agent returns:

- Latest News
- Supporting Articles
- Public Information

---

### Step 6 — Collaborative Reasoning

The Team Agent combines the outputs received from both agents.

The LLM analyzes:

- Financial Information
- Market News
- Company Context
- Analyst Opinions

before generating the final response.

---

### Step 7 — Final AI Response

The system returns a comprehensive response containing:

- Financial Summary
- Analyst Recommendations
- Latest News
- Supporting Context
- Source-Backed Insights
